بروتوكولات الأكواد والموجة اللاسلكية (Radio Wave Protocols)

الأكواد العامة (Codes) معنى الكود وتفسيره الميداني أكواد اليونتات الحركية المعنى والإجراء المتخذ فوراً حذف
Code 0 Security alert | استنفار أمني شامل (أعلى درجات الخطر) 0-1 استراحه او تسجيل خروج مؤقت من الموجة
Code 1 Close the svati | اغلق السفاتي والأنوار التنبيهية 0-2 الإشارة واضحة ومفهومة (علم)
Code 2 Safty works only | تشغيل الأنوار التنبيهية (السفاتي) بدون صوت 0-3 التأكد من إشارة وجودة الراديو واللاسلكي
Code 3 Safati works | تشغيل السفاتي والونات معاً (حالة طارئة جداً) 0-4 إلغاء البلاغ الحالي والعودة للميدان
Code 4 The place is safe | المكان آمن وخالي تماماً من التهديدات 0-5 الشرطي مشغول في حالة ميدانية لا تسمح بالكلام
Code 5 Case completed | تم الانتهاء من الحالة وإغلاق البلاغ بنجاح 0-6 كرر البلاغ أو الكلام الأخير (لم أسمعك جيداً)
Code 6 Status is being checked | جاري فحص وتدقيق الحالة أو المركبة 0-7 تسجيل خروج نهائي من الخدمة (أوف دوتي)
Code 7 فلتش أو سحر (مشكلة تقنية في المدينة خارجة عن الإرادة) 0-8 تسجيل دخول للخدمة وبدء الدورية (أون دوتي)
Code 8 Fingerprint scanning | مسح البصمات وجمع الأدلة الجنائية - -

شروط الخروج الآمن والهروب والأعطال الجسيمة (Exit & Escape Failures)

🛡️ شروط الخروج الآمن وبدء إطلاق النار التكتيكي | Safe exit conditions
  • 1 - التدخل الخارجي المباشر: في حال تدخل سيارات أو أفراد لمساعدة المجرم أثناء المطاردة، يحق للشرطة فتح النار فوراً.
  • 2 - دخول الورشة أو تعديل المركبة: إذا قام المشتبه به بدخول الورشة لإصلاح المركبة أو صبغها أثناء المطاردة النشطة، يُلغى الخروج الآمن.
  • 3 - رفع السلاح الناري على العساكر: التهديد بالسلاح أو رفعه بشكل صريح وواضح في وجه أفراد الدورية يعطي الحق بالتصفية الفورية.
  • 4 - تعريض حياة المواطنين للخطر: إذا قام الهارب بصدم المواطنين عمداً أو السير في أرصفة المشاة بشكل متكرر ومتعمد يعرض حياتهم للهلاك.
  • 5 - مهلة السلاح عند الهروب على الأقدام: في حال النزول من المركبة ومحاولة الهروب على الأقدام مع إخراج سلاح، إذا لم يقم بإدخاله في الحقيبة خلال 5 ثوانٍ، يتم إطلاق النار عليه بشكل فوري.
  • 6 - تغيير المركبة: الانتقال من مركبة إلى مركبة أخرى أثناء المطاردة يسقط شرط الخروج الآمن.
  • 7 - التوجه أو الاقتراب من البحر: محاولة الهروب عن طريق البحر أو استخدام القوارب والسباحة تسقط كافة وعود التهدئة.
  • 8 - الهروب على الأقدام بدون سلاح: في حال النزول ومحاولة الهروب بدون سلاح على الأقدام، يحق للعسكري استخدام الصاعق الكهربائي (التيزر) مباشرة لشل حركته واعتقاله.
